# 经典项目借鉴说明

FileScope 保留已有 Python 实现，参考成熟工具的设计与检测流程，不是完整复刻某一个仓库，也未把其代码整体移入项目。

## fdupes

- 阅读版本：2.4.0，commit `5e86f87042b6472a4871881435fae1cc438f12d0`。
- 来源：[版本仓库](https://github.com/adrianlopezroche/fdupes/tree/v2.4.0)。
- 关注入口：`fdupes.c`、`confirmmatch.c`。
- 借鉴：先按大小筛选、哈希候选后确认实际内容、识别同一物理文件的硬链接、检查读取前后的文件变化。
- FileScope 对应：`src/filescope.py` 中的大小分组、SHA-256、分块内容比较和属性检查。
- 证据范围：已阅读源码；截至本记录，未完成 fdupes 二进制运行，不宣称已与其逐项实测一致。

## dupeGuru

- 阅读版本：4.3.1，commit `1f1dfa88dc5f6ffe13f4de514c884ab9c83bd7ce`。
- 来源：[版本仓库](https://github.com/arsenetar/dupeguru/tree/4.3.1)。
- 借鉴：检测核心与展示分离、结果按组组织、明确每组保留文件和候选副本。
- FileScope 对应：网页入口、扫描服务、数据库、报告模块分工；详情页区分保留项与隔离候选。
- 差异：dupeGuru 是桌面应用；FileScope 使用 Flask 网页，不模仿其 Qt 界面。
- 证据范围：此前独立对照中运行过官方 Windows 便携版及核心扫描；基础测试数据得到相同的三组结果。这不是所有模式或性能的一致性证明。
